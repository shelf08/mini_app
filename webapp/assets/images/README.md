# Assets (картинки игры)

Складывай все изображения сюда:

- `webapp/assets/images/`

Текущий размер canvas в игре: **360×640** (портрет).
Чтобы на любых экранах было чётко, лучше экспортировать спрайты **в 2 раза больше** (2x) и уже в коде масштабировать под нужные размеры.

## Имена файлов (что нужно прислать)

### Фон
- `bg.png` или `bg.jpg`

### Игрок (3 положения)
- `player_l.png`
- `player_m.png`
- `player_r.png`

### Падающий “кекс” (обычный / золотой)
- `cake.png`
- `cake_gold.png`

### Бомба
- `bomb.png`

## Формат / прозрачность

- **Спрайты** (`player_*.png`, `cake*.png`, `bomb.png`): **PNG с прозрачным фоном (alpha)**.
- **Фон** (`bg.*`): PNG или JPG, прозрачность не нужна.

## Рекомендуемые размеры (разрешение файлов)

### Фон
Выбирай один вариант (или больше — не страшно):

- **720×1280** (2x от canvas) — минимум
- **1080×1920** (3x) — оптимально

Важно: фон должен быть в **портретной ориентации**, без мелких деталей по краям (могут обрезаться при адаптации).

### Игрок (3 положения)
- **240×240 px** (2x)

В игре это будет рисоваться примерно как **120×120** на canvas.
Если у персонажа “корзина/руки” широкие — можно сделать чуть шире, например **300×240** (2x).

### Кекс (обычный/золотой) и бомба
- **96×96 px** (2x)

В игре это будет рисоваться примерно как **48×48** на canvas.

## Важное про отступы
- Оставляй **2–6% прозрачного поля** по краям спрайта, чтобы при масштабировании ничего не “резалось”.
- Центрируй объект внутри картинки (так проще позиционировать по центру дорожки).
