# Assets (музыка)

Складывай фоновую музыку сюда:

- `webapp/assets/audio/`

## Имя файла по умолчанию

Положи один из файлов:

- `bgm.mp3` (рекомендуется)
- `bgm.ogg` (fallback)

Музыка будет играть **по кругу** пока мини‑апп открыт.

Примечание: некоторые WebView/браузеры **блокируют автозапуск со звуком**, поэтому музыка может стартовать после первого свайпа/тапа/клика.
